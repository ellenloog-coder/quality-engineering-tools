统计与算法说明

统计结果成立需要哪些条件？

说明统计分析使用前需要满足的基本条件，包括数据代表性、测量系统、过程稳定性、独立性、分布假设、样本量以及规格来源，并说明这些因素如何影响 Cpk、MSA、SPC、DOE 和可靠性分析等统计结果的有效性。

快速结论

  • 数据必须能代表实际过程的主要变化来源，试产或特殊批次数据不能代表量产状态；
  • 测量系统误差过大时，分析结果反映的可能不是产品变化；
  • 过程漂移或存在特殊原因时，直接计算能力指数可能产生误导；
  • 数据特征必须匹配统计方法的假设：数据类型、分布特征与独立性；
  • 样本量需要与分析目的匹配，过少会导致估计不稳定；
  • 规格边界来自设计、客户或工程要求，不能由统计计算替代。

核心结论

统计结果是否可信，取决于数据代表性、测量系统、过程稳定性、方法假设与规格来源。计算公式正确只是必要条件，不是充分条件。

工程注意

连续测量数据可能随时间漂移。忽略时间顺序、批次关系和趋势，可能低估过程风险。

常见误区

数字明确不等于结论可信。Cpk = 1.67 或 GRR = 12% 只有在数据与分析前提成立时才具有工程意义。

统计结果为什么需要前提条件？

在质量工程中，统计分析经常用于支持重要决策：

  • 当前过程是否满足规格要求？
  • 测量系统是否能够支持质量判断？
  • 过程是否处于稳定状态？
  • 哪些因素真正影响产品表现？
  • 产品寿命是否满足可靠性目标？

这些判断通常来自统计结果。例如：

Cpk = 1.67

或者：

GRR = 12%

数字本身看起来明确，但一个统计结果是否具有工程意义，并不只取决于计算公式是否正确。

统计方法都有自己的适用条件。如果输入数据不能代表实际过程，测量系统无法反映真实变化，或者过程本身处于异常状态，即使计算过程完全正确，最终结论仍可能产生误导。

因此，在进行任何统计分析之前，需要先确认：

这个数据是否适合使用这个方法？这个结果是否能够支持工程判断？

1. 数据需要具有代表性

统计分析的基础是数据，但并不是所有数据都能够代表实际问题。

例如，一个生产过程每天生产数千件产品，如果分析数据只来自：

  • 某一次试产；
  • 某一个特殊批次；
  • 某一个表现较好的时间段；

那么分析结果可能无法反映真实量产状态。

有效的数据通常需要覆盖实际过程中的主要变化来源，例如：

  • 不同生产时间；
  • 正常设备状态；
  • 典型材料和工艺条件；
  • 真实生产环境。

对于过程能力分析，Cpk 和 Ppk 评价的是过程表现，而不是某一次测量结果。对于 DOE，实验数据需要能够代表研究范围内的因子变化。对于可靠性分析，失效数据需要能够反映产品真实使用条件。

2. 测量系统需要可靠

统计分析建立在测量数据之上。如果测量系统本身存在较大误差，分析结果可能反映的是测量变化，而不是产品变化。

例如：产品尺寸实际变化：

±0.05 mm

但测量系统误差：

±0.08 mm

此时无法准确判断：

  • 产品是否稳定；
  • 过程是否改善；
  • 波动来自哪里。

因此，在使用统计方法之前，需要确认：

  • 测量设备是否适用；
  • 测量方法是否一致；
  • 测量误差是否在可接受范围内。

这也是为什么 MSA（Measurement System Analysis）通常被认为是质量统计分析的重要基础。

3. 过程需要处于稳定状态

很多统计方法默认过程变化主要来自正常波动。但制造过程可能受到设备调整、原材料变化、操作者变化、环境变化、工艺漂移等因素影响。

例如，一个尺寸过程第一周：

平均值 = 10.00 mm

第二周：

平均值 = 10.15 mm

如果直接合并计算，可能得到一个表面合理的能力指数。但实际上，过程已经发生漂移。

因此，在评价过程能力之前，需要确认过程是否稳定。SPC 控制图的作用，就是帮助识别：

  • 普通原因变化；
  • 特殊原因变化；
  • 趋势和异常信号。

4. 数据需要符合统计方法的假设

不同统计方法适用于不同类型的数据。例如，传统过程能力分析通常基于：

  • 连续测量数据；
  • 稳定过程；
  • 适当的数据分布。

但实际工程中，不同数据可能具有不同特点：

  • 尺寸测量数据；
  • 缺陷数量数据；
  • 寿命数据；
  • 失效时间数据。

如果数据特征与方法假设不匹配，结果可能无法准确描述实际情况。因此，需要确认数据类型、分布特征以及分析方法是否适用。

5. 数据点需要满足独立性要求

许多统计方法假设每一个数据点代表独立的信息，但制造现场的数据可能存在关联。例如，连续测量结果：

10.01
10.02
10.03
10.04

可能不是随机变化，而是设备正在逐渐漂移。如果忽略这种趋势，可能低估过程风险。

因此，需要关注：

  • 数据采集方式；
  • 时间顺序；
  • 批次关系；
  • 连续变化趋势。

6. 样本数量需要支持统计判断

统计分析使用样本推断过程。样本数量过少时：

  • 平均值估计可能不稳定；
  • 波动范围可能无法充分体现；
  • 极端值影响可能被放大。

例如，几个测量值看起来非常集中，并不代表长期生产一定稳定。随着样本数量增加：

  • 过程中心估计更加可靠；
  • 波动估计更加稳定；
  • 统计判断更加可信。

因此，样本量需要与分析目的匹配。

7. 规格要求必须来源明确

许多统计指标需要规格边界：

  • LSL（Lower Specification Limit）
  • USL（Upper Specification Limit）
  • Target

例如，Cpk 计算需要知道过程距离规格中心还有多少空间。但规格本身不是统计计算产生的，它应该来自：

  • 产品设计要求；
  • 客户要求；
  • 工程规范；
  • 法规要求。

统计工具可以评价：

当前过程相对于既定要求的能力。

但不能替代工程定义规格。

8. 不同统计工具关注不同前提

虽然 Cpk、MSA、SPC、DOE 和可靠性分析都属于统计方法，但关注重点不同。

工具主要关注条件
Cpk / Ppk数据代表性、过程稳定性、分布、规格要求
SPC时间顺序、过程稳定性、异常信号
MSA测量系统能力、重复性、再现性
DOE实验设计、因子定义、随机化
Reliability失效数据完整性、分布模型

因此，没有一种统计方法可以脱离工程背景单独使用。

总结

统计分析并不是从公式开始，而是从问题定义和数据条件开始。一个可信的统计结果，需要建立在：

  • 具有代表性的数据；
  • 可靠的测量系统；
  • 稳定的过程状态；
  • 合适的统计方法；
  • 足够的样本数量；
  • 明确的工程规格。

Blendex Labs 希望帮助工程人员不仅获得统计结果，也理解：

什么时候这个结果可以被相信，以及它能够支持什么样的工程决策。
