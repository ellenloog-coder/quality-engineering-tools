# 我应该使用哪个质量工具？

质量工程中有很多常见工具：过程能力分析、MSA、SPC、8D、DOE、可靠性分析……它们看起来都与数据、变差和质量改善有关，但解决的问题并不相同。

实际工作中，最常见的错误往往不是公式算错了，而是一开始就选错了方法：过程还不稳定就根据 Cpk 决定放行；测量系统不可靠却用测量结果判断产品和供应商；已经发生重复性客诉却只做一张控制图；想找到关键工艺参数却一直进行单因素试验；产品通过一次功能测试就认为能够满足设计寿命。

选择工具之前，不需要先理解所有统计术语。你只需要先回答一个问题：**我现在真正想解决的是什么问题？**

## 快速理解

- 不确定数据是否可信：使用 **MSA**
- 想判断过程是否稳定：使用 **SPC**
- 想判断过程能否满足规格：使用 **过程能力分析**
- 想系统解决已经发生的质量问题：使用 **8D**
- 想找到关键因素并优化参数：使用 **DOE**
- 想评估产品寿命和时间相关失效：使用 **Reliability**

这些工具并不是彼此替代的关系。一个完整的工程问题，经常需要组合使用多种方法：**MSA 确认数据可信 → SPC 判断过程状态 → 过程能力分析判断规格余量 → DOE 优化关键参数。**

## 一、过程能力分析解决什么问题？

过程能力分析用于判断一个过程产生的结果，是否具备持续满足规格的能力。它比较过程数据分布与规格限之间的关系，通常回答过程输出是否满足规格、变差相对于公差是否过大、均值是否偏向规格上限或下限、组内变差与整体变差是否一致，以及当前数据是否支持放行或改善决策。

### 典型场景

假设某个灌装过程的规格是 500 ± 5 g。你已经收集了一批生产数据，现在想判断灌装重量是否落在 495—505 g 之间、平均重量是否偏离 500 g、当前过程波动是否过大、不同批次之间是否存在额外差异，以及当前表现是否足以支持量产放行。这时，应考虑使用过程能力分析。

### 过程能力分析不能单独证明什么？

能力指数不能单独证明测量系统可靠、过程处于统计稳定状态、数据覆盖正常生产条件、异常原因已经找到、未来批次一定保持当前表现，或产品的全部风险已经得到控制。进行能力分析前，通常还需要确认测量数据可信、数据具有生产代表性、过程稳定，以及规格、单位和分组方式正确。

## 二、MSA 解决什么问题？

MSA，即测量系统分析，用于判断我们看到的差异究竟来自产品本身，还是来自测量系统。测量结果可能受到设备、检验员、测量方法、夹具和定位、环境条件、样件状态以及重复测量随机波动的影响。

### 常见 MSA 方法

- **Gage R&R**：适用于长度、重量、厚度、扭矩、电压、间隙等连续测量数据，判断重复性、再现性以及测量误差相对于产品变差或公差是否过大。
- **Attribute Agreement / Kappa**：适用于合格/不合格、划痕、缺陷等级和外观判断，评估检验员自身、检验员之间以及检验员与参考标准的一致性。
- **Cg / Cgk**：通常用于评估单台测量设备在受控条件下的短期能力。

### 什么时候应优先做 MSA？

同一样件反复测量结果不同、不同检验员结论不一致、供应商与客户测量结果不一致、能力结果异常波动、数据接近规格边界、改善前后差异很小或外观检验争议频繁时，应首先检查测量系统。

## 三、8D 解决什么问题？

8D 是一套结构化的问题解决流程，适用于已经发生，并且需要跨职能团队系统调查、控制和关闭的质量问题。典型场景包括客户投诉、重复性退货、批量不良、产品安全问题、关键功能失效、供应商重大质量异常、问题再次发生，以及原因复杂并涉及多个部门或过程的情况。

单次低风险且原因明确的小问题、可以立即纠正的录入错误、不影响客户和产品功能的轻微内部异常，或已有明确标准流程的问题，未必需要完整 8D，可以考虑快速纠正、5 Why、简化 CAPA、现场异常记录或日常问题管理流程。

## 四、什么时候使用 SPC？

SPC，即统计过程控制，用于判断过程是否随时间保持稳定，还是出现特殊原因变化。它帮助识别突然偏移、持续趋势、周期性变化、异常波动、换班换料或换设备后的变化，以及过程状态是否已经改变。

SPC 回答“过程是否稳定？”；过程能力分析回答“过程与规格之间是否有足够余量？”一个过程可能稳定但能力不足，也可能能力指数较高但过程不稳定。

## 五、什么时候使用 DOE？

DOE，即实验设计，用于回答哪些因素真正影响结果、因素之间是否存在交互作用，以及参数应该如何设置。它适合在可以有计划地改变输入条件并观察输出结果时使用，能够更高效地估计主效应、交互作用、显著因素、推荐设定和可接受参数窗口。

问题范围尚未定义、输出数据不可靠、实验条件无法控制、关键因素无法改变、重大客户风险尚未完成临时控制，或只是想证明预先决定好的结论时，不应直接使用 DOE。

## 六、什么时候使用 Reliability？

Reliability，即可靠性分析，用于评估产品在规定条件和规定时间内持续完成预期功能的能力。它关注产品能够工作多久、失效率如何随时间变化、是否存在早期失效或磨损失效、设计寿命是否满足要求、加速测试是否代表实际使用，以及哪些应力会触发失效机理。

常见方法包括 Weibull 分析、Life Data Analysis、Reliability Demonstration、Accelerated Life Testing、HALT/HASS、Stress-Strength Analysis、Mission Profile 分析，以及 MTBF、MTTF 和失效率分析。

过程能力关注制造输出在当前状态下是否满足规格；可靠性关注产品在使用时间和环境应力下能否持续满足功能。产品出厂时尺寸合格，并不代表它在使用一年后不会断裂、老化、磨损或性能衰减。

## 七、一个简单的问题选择流程

1. 如果不确定当前数据是否可信，优先使用 **MSA**。
2. 如果已经出现客户投诉、批量不良、重复性退货、产品安全问题、重大供应商异常或关键功能失效，优先启动 **8D**。
3. 如果想监控趋势、偏移、异常点、特殊原因或过程状态变化，使用 **SPC**。
4. 当数据可信、过程状态得到确认后，使用 **过程能力分析** 判断变差、均值偏移和规格余量。
5. 如果存在多个可能的输入因素并且可以安排受控试验，使用 **DOE**。
6. 如果问题与寿命或时间相关失效有关，使用 **Reliability**。

## 八、快速选择表

| 你正在问的问题 | 优先考虑的工具 |
|---|---|
| 我的测量结果可信吗？ | MSA |
| 不同检验员为什么判断不一致？ | MSA |
| 过程是否随时间稳定？ | SPC |
| 过程是否能够满足规格？ | 过程能力分析 |
| 为什么这个质量问题会发生？ | 8D |
| 为什么现有控制没有发现问题？ | 8D |
| 哪些参数真正影响结果？ | DOE |
| 最佳工艺参数应该如何设置？ | DOE |
| 产品能否达到设计寿命？ | Reliability |
| 现场失效是否与时间或应力有关？ | Reliability |
